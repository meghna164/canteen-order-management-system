
# Canteen Order Management System

## About the Project
The Canteen Order Management System is a web application developed using Python, Streamlit, and SQLite. It helps manage food items, customer orders, billing, and sales reports.

## Features
- Dashboard for order and sales overview
- Food menu management
- Add items to cart and place orders
- Generate and download bill receipts
- Order history and status management
- Sales reports and charts
- SQLite database for storing information

## Technologies Used
- Python
- Streamlit
- SQLite
- Pandas

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the dependencies:

   `python -m pip install -r requirements.txt`

4. Run the application:

   `python -m streamlit run app.py`

5. Open the local URL displayed in the terminal.

## Project Objective
To simplify canteen operations by managing menu items, recording orders, generating bills, and tracking sales.
